# Engineering Onboarding Guide

Welcome to **Kestrel Cloud Engineering**! This guide covers your first week setup.

## Day 1 Checklist
- Request access to GitHub org `kestrel-cloud`, PagerDuty, and Grafana via the IT portal.
- Clone the monorepo and verify your Dev Container boots cleanly with `docker compose up -d`.
- Complete the mandatory Secure Coding & Data Privacy module before requesting staging credentials.

## Key Channels
- `#eng-announcements`: Org-wide releases and maintenance windows
- `#ask-platform`: CI/CD, Kubernetes, and database support
- `#sec-help`: Threat modeling and credential rotation questions
